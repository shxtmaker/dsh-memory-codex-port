# V0.2.0

记忆功能用量由单次报警改为今日 token 消耗统计。

- 移除报警阈值、阈值保存按钮和超额提示。
- 在高级设置原用量说明处显示「每次提炼、整理和重试分别按供应商返回的总 tokens 计量。今日已使用 N token。」
- 提炼、整理、失败和重试按供应商实际总 tokens 分别累计。流式调用后续失败时保留已经收到的用量；未知用量单独提示，不补算为零。
- 按执行主机本地自然日统计，支持跨日和夏令时，重启保留统计。清空记忆内容不清除已经记录的消耗。旧版本用量不回填。
- 保留已配置供应商与模型选择、官方路由默认选择、最新状态折叠及同行控件上下对齐。
- 重写 README，补充安装、使用、统计口径和升级说明。

兼容 Host 0.2.0-rc.2，Node.js 24 或更新版本。安装后必须完整退出并重新启动相同 home/profile 的 Host。

构建、类型检查、15 项自动化检查、固定模型原生 Host 闭环及实际隔离 loopback Web 页面验证通过。真实 Desktop 页面、真实供应商调用和跨机器远程/WAN 未在本版本验证。

附件提供插件安装包、完整源码和 SHA-256 校验值。
